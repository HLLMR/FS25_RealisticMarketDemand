# Security Policy

This is a single-player Farming Simulator 25 game mod (Lua scripts). It runs
inside the GIANTS Engine, has no network/server component of its own, and stores
data only in your local savegame folder — so the security surface is small.

## Reporting

If you find a security-relevant issue (for example, something that could corrupt
a savegame, or unexpected file access), please report it privately via GitHub's
**"Report a vulnerability"** (Security → Advisories) rather than a public issue,
or contact the maintainer **@HLLMR**.

For ordinary bugs, open a normal [issue](https://github.com/HLLMR/FS25_RealisticMarketDemand/issues).

## Supported versions

Only the latest released version receives fixes.
